基础：
touch 文件名------------------->创建文件
git add .---------------->工作区到暂存区
git commit -m '注释'------------>暂存区到仓库
git status---------------------->查看状态
git log/git-log---------------->查看提交记录
git reset --hard 版本id----------->版本回退


分支：
git branch 分支名--------->创建分支
git checkout 名字----------->指向分支
git checkout -b 名字------------>创建并指向分支
git merge 分支名---------------->合并
git branch -d 分支名------------>删除分支
git branch -D 分支名------------->强制删除分支

推送到远程仓库：
git push [-f] [--set-upstream] 远端名 本地分支名----------------->-f是强制覆盖
